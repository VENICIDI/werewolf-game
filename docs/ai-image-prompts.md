## F. 补充说明

### F1. 生图参数建议

| 参数 | 推荐值 |
|------|--------|
| **模型** | SDXL / Midjourney v6 / DALL-E 3 / Flux |
| **采样器** | DPM++ 2M Karras（SD系列） |
| **步数** | 30-50 步 |
| **CFG Scale** | 7-9 |
| **图片格式** | PNG（保留透明通道） |
| **后处理** | 需要用 PS/Figma 去背景、裁切、调整透明度 |

### F2. 风格一致性要点

1. **色温统一**: 所有图片偏暖暗色调（dark warm），避免冷蓝色调
2. **主色调**: 血红 `#8b0000~#c41a1a`、暗金 `#d4af37`、深棕 `#1a1510~#2a2018`
3. **画风**: 半写实暗黑奇幻（Semi-realistic Dark Fantasy），不要卡通/二次元
4. **光照**: 统一为低光照环境，主光源为血月/烛火/魔法光
5. **氛围**: 始终保持神秘、黑暗、哥特的氛围感

### F3. 后处理注意事项

| 图片类型 | 后处理步骤 |
|----------|-----------|
| TabBar 图标 | 去背景 → 缩放到 81×81 → 检查线条清晰度 |
| 背景图 | 调整透明度/混合模式 → 边缘羽化 → 导出 WebP（减小体积） |
| 角色卡面 | 去背景或统一暗色渐变背景 → 裁切到 200×260 |
| 阶段横幅 | 确保中央区域足够暗以放置白色/金色文字 |
| 装饰元素 | 精确去背景 → 调整为指定颜色 → 检查边缘锯齿 |
| 所有图标 | 可考虑统一在 Figma 中用矢量重绘，AI 生图作为参考 |
