## 1. 整体架构

```
┌─────────────────────────────────────────────────────────────┐

## 2. 游戏宏观状态机

### 2.1 状态定义

| 状态 | 枚举值 | 描述 |
|------|--------|------|
| 等待中 | `PREPARING` | 等待玩家加入房间并准备 |
| 进行中 | `RUNNING` | 游戏进行中（夜晚/白天循环） |
| 暂停 | `PAUSED` | 游戏暂停 |
| 已结束 | `FINISHED` | 游戏结束，产生获胜方 |

### 2.2 状态流转图

```
                        ┌─────────────────────────────────────────┐
                        │              重新开始                     │
                        │                                         │
                        v                                         │
                 ┌─────────────┐                                  │
                 │   waiting   │                                  │
                 │  (PREPARING)│                                  │
                 └──────┬──────┘                                  │
                        │ 人数 >= 6 且全部准备                      │
                        v                                         │
                 ┌─────────────┐                                  │
                 │  starting   │                                  │
                 │  分配角色    │                                  │
                 └──────┬──────┘                                  │
                        │ 自动进入第1夜                             │
                        v                                         │
              ┌──────────────────┐                                │
         ┌───>│     night        │                                │
         │    │ (RUNNING/夜晚)   │                                │
         │    └────────┬─────────┘                                │
         │             │ 夜晚所有阶段结束                           │
         │             │ → resolveNight() 结算                     │
         │             v                                          │
         │    ┌──────────────────┐                                │
         │    │      day         │                                │

## 3. 夜晚阶段流程

### 3.1 阶段序列

夜晚由 `PhaseScheduler` 按照 `game-flow.json` 中的配置顺序依次调度：

```
┌───────────────┐    ┌───────────────────┐    ┌────────────────┐
│  night_start  │───>│  werewolf_action  │───>│  seer_action   │
│   天黑请闭眼   │    │   狼人选择击杀目标  │    │  预言家查验目标  │
│    (3秒)      │    │     (30秒)        │    │    (20秒)      │
└───────────────┘    └───────────────────┘    └───────┬────────┘
                                                      │
              ┌───────────────────────────────────────┘
              │
              v
┌──────────────────┐    ┌────────────────┐    ┌─────────────────┐
│  guard_action    │───>│  witch_action   │───>│ hunter_action   │
│  守卫选择守护目标 │    │ 女巫救人/毒人    │    │   猎人确认身份   │
│   (20秒)*       │    │    (30秒)       │    │    (15秒)       │
└──────────────────┘    └────────────────┘    └────────┬────────┘
                                                       │
  * 守卫仅在 12 人局中出现                                │ 所有阶段完成
                                                       v
                                              ┌─────────────────┐
                                              │  resolveNight() │
                                              │    夜晚结算      │
                                              └─────────────────┘
```

### 3.2 阶段详情

| 阶段 | GamePhase 枚举 | 时长 | 关联角色 | 可执行行动 |
|------|---------------|------|---------|-----------|
| night_start | `NIGHT_START` | 3s | — | — |
| werewolf_action | `WEREWOLF` | 30s | 狼人 | `kill` |
| seer_action | `SEER` | 20s | 预言家 | `check` |
| guard_action | `GUARD` | 20s | 守卫 | `guard` |
| witch_action | `WITCH` | 30s | 女巫 | `save` / `poison` |
| hunter_action | `HUNTER` | 15s | 猎人 | — (被动确认) |

## 4. 白天阶段流程

### 4.1 阶段序列

```
┌───────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   day_start   │───>│ announce_death   │───>│   discussion    │
│    天亮了      │    │   公布昨晚死亡    │    │   玩家轮流发言   │
│    (3秒)      │    │    (10秒)        │    │  (180s/240s)    │
└───────────────┘    └──────────────────┘    └───────┬─────────┘
                                                     │
                                                     v
                                             ┌───────────────┐
                                             │    voting      │
                                             │   投票放逐      │
                                             │    (30秒)      │
                                             └───────┬────────┘
                                                     │
                                                     v
                                             ┌────────────────┐
                                             │   execution    │
                                             │  公布投票结果    │
                                             │  处决 / 遗言    │
                                             │    (10秒)      │
                                             └────────────────┘
```

### 4.2 阶段详情

| 阶段 | GamePhase 枚举 | 时长 | 描述 |
|------|---------------|------|------|
| day_start | `DAY_START` | 3s | 天亮了，系统提示 |
| announce_death | `DAY_START` | 10s | 公布昨晚死亡玩家，允许遗言 |
| discussion | `DISCUSSION` | 180s(9人) / 240s(12人) | 存活玩家按座位顺序发言 |
| voting | `VOTING` | 30s | 投票选出放逐目标，可弃票 |
| execution | `EXECUTION` | 10s | 公布投票结果，处决最高票玩家 |

## 6. 夜晚结算逻辑

`NightActionStore.RoundActions.resolveNight()` 执行以下流程：

```
                    ┌──────────────────┐
                    │  狼人击杀目标     │
                    │ (多狼投票取最高票) │
                    └────────┬─────────┘
                             │
                             v
                    ┌──────────────────┐
                ┌──>│  是否被守卫守护?  │
                │   └────────┬─────────┘
                │          是│       否
                │            v        │
                │   ┌────────────┐    │
                │   │ isGuarded  │    │
                │   │  = true    │    │
                │   └────────────┘    │
                │                     v
                │            ┌──────────────────┐
                │        ┌──>│  是否被女巫救?    │
                │        │   └────────┬─────────┘
                │        │          是│       否
                │        │            v        │
                │        │   ┌────────────┐    │
                │        │   │  isSaved   │    │
                │        │   │  = true    │    │
                │        │   └────────────┘    │
                │        │                     │
                │        v                     v
                │  ┌───────────────────────────────┐
                │  │         判定存亡               │
                │  │                               │
                │  │  同守冲突 (isGuarded && isSaved)│
                │  │    → 玩家死亡 ☠️               │
                │  │                               │
                │  │  仅一方保护 (isGuarded ^ isSaved)│
                │  │    → 玩家存活 ✅               │
                │  │                               │
                │  │  无人保护 (!isGuarded && !isSaved)│
                │  │    → 玩家死亡 ☠️               │
                │  └───────────────┬───────────────┘
                │                  │
                │                  v
                │         ┌──────────────────┐
                │         │  女巫毒人?        │
                │         │  (额外死亡目标)   │
                │         └────────┬─────────┘
                │                  │
                │                  v
                │         ┌──────────────────┐
                └────────>│  返回死亡玩家列表  │
                          └──────────────────┘
```

### 结算规则总结

| 场景 | 守卫 | 女巫 | 结果 |
|------|------|------|------|
| 无人保护 | ✗ | ✗ | **死亡** |
| 仅守卫保护 | ✓ | ✗ | 存活 |
| 仅女巫救 | ✗ | ✓ | 存活 |
| 同守冲突 | ✓ | ✓ | **死亡** (特殊规则) |

## 7. 胜负判定

`GameService.checkWinCondition()` 在以下时机触发：
- 夜晚结算后
- 白天投票处决后
- 猎人开枪后

```
┌───────────────────────────────────────────┐
│            胜负判定流程                     │
│                                           │
│   统计存活玩家:                            │
│   • werewolfCount  = 存活狼人数            │
│   • godCount       = 存活神职数            │
│   • civilianCount  = 存活平民数            │
│   • aliveVillager  = 存活好人总数          │
│                                           │
│   ┌─────────────────────────────┐         │
│   │ werewolfCount == 0 ?       │── 是 ──> 村民阵营获胜 🏆
│   └──────────┬──────────────────┘         │
│              │ 否                          │
│   ┌──────────v──────────────────┐         │
│   │ godCount == 0 ?            │── 是 ──> 狼人阵营获胜 🐺
│   └──────────┬──────────────────┘         │
│              │ 否                          │
│   ┌──────────v──────────────────┐         │
│   │ civilianCount <= 0 ?       │── 是 ──> 狼人阵营获胜 🐺
│   └──────────┬──────────────────┘         │
│              │ 否                          │
│   ┌──────────v──────────────────┐         │
│   │ werewolfCount >= villager? │── 是 ──> 狼人阵营获胜 🐺
│   └──────────┬──────────────────┘         │
│              │ 否                          │
│              v                            │
│         游戏继续                           │
└───────────────────────────────────────────┘
```

## 8. 行动系统

所有游戏行动通过统一的 `POST /api/games/{gameId}/action` 接口提交，由 `ActionDispatcher` 路由到对应处理器。

### 8.1 行动分发流程

```
客户端请求
    │
    v
┌──────────────────┐
│  GameController   │  POST /api/games/{gameId}/action
│  submitAction()   │  { action: "kill", targetId: 5 }
└────────┬─────────┘
         │
         v
┌──────────────────┐
│  GameService      │
│  executeAction()  │
│                   │
│  • 权限校验        │
│  • 死亡校验        │
│  • 重复提交校验    │
└────────┬─────────┘
         │
         v
┌──────────────────┐    ┌─────────────────────────────┐
│ ActionDispatcher  │───>│  GameActionHandler          │
│  dispatch()       │    │                             │
│                   │    │  validate() → 校验行动合法性 │
│  action 路由      │    │  execute()  → 执行行动逻辑   │
└──────────────────┘    └─────────────────────────────┘
         │
         v
┌──────────────────┐
│  后续处理         │
│                   │
│  • 记录日志       │
│  • WebSocket 确认 │
│  • 自动结算判定    │
└──────────────────┘
```

### 8.2 行动类型一览

| 行动 | action 值 | 处理器 | 使用阶段 | 关联角色 | 说明 |
|------|----------|--------|---------|---------|------|
| 狼人击杀 | `kill` | WerewolfKillHandler | 夜晚 WEREWOLF | 狼人 | 选择击杀目标，多狼投票取最高票 |
| 预言家查验 | `check` | SeerCheckHandler | 夜晚 SEER | 预言家 | 查验目标身份(好人/狼人) |
| 女巫救人 | `save` | WitchSaveHandler | 夜晚 WITCH | 女巫 | 使用解药救当晚被杀玩家 |
| 女巫毒人 | `poison` | WitchPoisonHandler | 夜晚 WITCH | 女巫 | 使用毒药毒杀目标 |
| 守卫守护 | `guard` | GuardProtectHandler | 夜晚 GUARD | 守卫 | 守护目标，不可连续守同一人 |
| 投票放逐 | `vote` | VoteHandler | 白天 VOTING | 所有存活 | 投票选出放逐目标 |
| 猎人开枪 | `shoot` | HunterShootHandler | 死亡触发 | 猎人 | 死亡时带走一人(被毒杀除外) |
| 跳过行动 | `skip` | SkipHandler | 任意 | 任意 | 放弃当前行动 |

## 9. 游戏模式配置

### 9.1 标准 9 人局 (`standard_9`)

```
┌─────────────────────────────────────────┐
│  角色分配: 3狼人 + 3村民 + 3神职         │
│                                         │
│  ┌──────┐ ┌──────┐ ┌──────┐            │
│  │ 🐺×3 │ │ 👤×3 │ │ 🔮×1 │            │
│  │ 狼人  │ │ 村民  │ │预言家│            │
│  └──────┘ └──────┘ └──────┘            │
│  ┌──────┐ ┌──────┐                     │
│  │ 🧪×1 │ │ 🔫×1 │                     │
│  │ 女巫  │ │ 猎人  │                     │
│  └──────┘ └──────┘                     │
│                                         │
│  特殊规则:                               │
│  • 女巫不能自救                           │
│  • 女巫第一夜可以救人                      │
│  • 猎人被毒杀不能开枪                      │
│  • 平票不处决                             │
└─────────────────────────────────────────┘
```

### 9.2 标准 12 人局 (`standard_12`)

```
┌─────────────────────────────────────────┐
│  角色分配: 4狼人 + 4村民 + 4神职         │
│                                         │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐  │
│  │ 🐺×4 │ │ 👤×4 │ │ 🔮×1 │ │ 🧪×1 │  │
│  │ 狼人  │ │ 村民  │ │预言家│ │ 女巫  │  │
│  └──────┘ └──────┘ └──────┘ └──────┘  │
│  ┌──────┐ ┌──────┐                     │
│  │ 🔫×1 │ │ 🛡×1 │                     │
│  │ 猎人  │ │ 守卫  │                     │
│  └──────┘ └──────┘                     │
│                                         │
│  特殊规则:                               │
│  • 女巫可以自救                           │
│  • 守卫不能自守                           │
│  • 守卫不能连续守同一人                    │
│  • 守卫+女巫同守 → 目标死亡              │
│  • 猎人被毒杀不能开枪                      │
│  • 平票不处决                             │
└─────────────────────────────────────────┘
```

### 9.3 新手 6 人局 (`beginner_6`)

```
┌─────────────────────────────────────────┐
│  角色分配: 2狼人 + 2村民 + 2神职         │
│                                         │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐  │
│  │ 🐺×2 │ │ 👤×2 │ │ 🔮×1 │ │ 🧪×1 │  │
│  │ 狼人  │ │ 村民  │ │预言家│ │ 女巫  │  │
│  └──────┘ └──────┘ └──────┘ └──────┘  │
│                                         │
│  特殊规则:                               │
│  • 第一夜不击杀                           │
│  • 女巫可以自救                           │
└─────────────────────────────────────────┘
```

## 10. 角色一览

| 角色 | 枚举值 | 阵营 | 类型 | 技能描述 |
|------|--------|------|------|---------|
| 村民 | `VILLAGER` | 好人 | 平民 | 无特殊技能，通过投票消灭狼人 |
| 狼人 | `WEREWOLF` | 狼人 | — | 每晚选择一名玩家击杀 |
| 预言家 | `SEER` | 好人 | 神职 | 每晚查验一名玩家的身份 |
| 女巫 | `WITCH` | 好人 | 神职 | 拥有一瓶解药(救人)和一瓶毒药(毒人)，各限用一次 |
| 猎人 | `HUNTER` | 好人 | 神职 | 死亡时可带走一名玩家(被毒杀除外) |
| 守卫 | `GUARD` | 好人 | 神职 | 每晚守护一名玩家免受狼人击杀，不可连续守同一人 |
| 白痴 | `IDIOT` | 好人 | 神职 | (预留角色) |

### 玩家状态

| 状态 | 枚举值 | 可投票 | 可发言 | 可使用技能 |
|------|--------|--------|--------|-----------|
| 存活 | `ALIVE` | ✓ | ✓ | ✓ |
| 死亡 | `DEAD` | ✗ | ✗ | ✗ |
| 濒死 | `DYING`* | ✗ | ✓ | ✓ (猎人开枪) |
| 掉线 | `DISCONNECTED` | ✗ | ✗ | ✗ |

> *濒死状态定义在 `game-states.json` 中，目前代码中使用 `DEAD` 状态 + 猎人特殊判定实现。

## 附录: WebSocket 消息类型

游戏过程中通过 WebSocket 广播以下消息：

| 消息类型 | 触发时机 | 接收方 |
|---------|---------|--------|
| `GAME_START` | 游戏开始 | 房间所有人 |
| `ROLE_ASSIGN` | 分配角色 | 仅本人 |
| `PHASE_CHANGE` | 阶段切换 | 房间所有人 |
| `ACTION_CONFIRM` | 行动确认 | 仅操作者 |
| `DEATH_ANNOUNCE` | 死亡公告 | 房间所有人 |
| `VOTE_START` | 投票开始 | 房间所有人 |
| `VOTE_RESULT` | 投票结果 | 房间所有人 |
| `HUNTER_SHOOT` | 猎人可开枪 | 仅猎人 |
| `GAME_OVER` | 游戏结束 | 房间所有人 |
| `SYSTEM` | 系统消息 | 房间所有人 |
