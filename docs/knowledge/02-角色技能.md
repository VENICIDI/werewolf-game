# 狼人杀角色技能详解

## 狼人阵营

### 狼人
- **技能**：每晚睁眼，与队友商量后选择一名玩家击杀
- **特性**：知道队友身份，可自爆
- **胜利条件**：好人全部死亡
- **策略**：隐藏身份，混淆视听，带节奏

### 狼王
- **技能**：死亡时可带走一名玩家（被毒死除外）
- **特性**：狼人阵营，有遗言
- **策略**：可以故意暴露吸引火力，带走关键神职

### 白狼王
- **技能**：白天可以自爆，带走一名玩家
- **特性**：狼人阵营，自爆可带走人
- **策略**：关键时刻自爆带走预言家或女巫

### 隐狼
- **技能**：预言家查验显示为好人
- **特性**：狼人阵营，但被查验为好人
- **策略**：隐藏更深，后期发力

## 神职阵营

### 预言家
- **技能**：每晚查验一名玩家身份（好人/狼人）
- **查验结果**：金水（好人）/ 查杀（狼人）
- **策略**：上警拿警徽，报查验，留警徽流
- **危险**：容易被狼人悍跳、被刀

### 女巫
- **技能**：
  - 解药：救活今晚被狼人击杀的玩家（不能自救）
  - 毒药：毒死一名玩家
- **限制**：解药和毒药不能同一晚使用，解药用过之后才能用毒药
- **策略**：首夜可自救的板子建议救人，毒药留给明狼
- **危险**：容易被狼人骗药

### 猎人
- **技能**：死亡时可开枪带走一名玩家（被毒死不能开枪）
- **特性**：有遗言，可自证身份
- **策略**：可以强势表水，不怕被投
- **注意**：被女巫毒死无法开枪

### 守卫
- **技能**：每晚守护一名玩家，使其当晚不会被狼人击杀
- **限制**：不能连续两晚守护同一人，不能守护自己
- **策略**：守护预言家或重要神职
- **配合**：与女巫配合可形成"守救守"战术

### 白痴
- **技能**：被投票处决时亮明身份，继续游戏但不能投票
- **特性**：免疫一次处决
- **策略**：可以故意表现得像狼，吸引投票

### 骑士
- **技能**：白天可以决斗一名玩家，如果对方是狼人则狼人死亡，否则骑士死亡
- **特性**：只能使用一次
- **策略**：在真假预言家对跳时决斗悍跳狼

### 丘比特
- **技能**：首夜选择两名玩家成为情侣
- **特性**：情侣同生共死，形成第三方阵营
- **策略**：根据情侣身份决定站边

## 平民阵营

### 平民
- **技能**：无特殊技能
- **胜利条件**：狼人全部死亡
- **策略**：认真听发言，逻辑推理，找狼坑
- **价值**：人数优势，可挡刀

## 第三方阵营

### 盗贼
- **技能**：首夜可以选择交换身份牌
- **特性**：可能加入任意阵营

### 吹笛者
- **技能**：每晚迷惑一名玩家
- **胜利条件**：迷惑所有存活玩家

## 角色克制关系

| 角色A | 克制 | 被克制 |
|-------|------|--------|
| 预言家 | 隐狼 | 悍跳狼、狼王 |
| 女巫 | 狼人刀法 | 狼王自爆 |
| 猎人 | 狼人 | 女巫毒药 |
| 守卫 | 狼刀 | 连续刀同一人 |
| 骑士 | 悍跳狼 | 真预言家被决斗 |

## 角色配合

### 黄金搭档
- **预言家 + 女巫**：预言家查验，女巫保护
- **守卫 + 女巫**：守救守，形成无敌盾
- **猎人 + 白痴**：双神威慑，狼人不敢轻动

### 危险组合
- **狼王 + 狼人**：狼王带走关键神职
- **白狼王 + 狼人**：白天带走预言家
