# AI 玩家策略指南

## AI 角色定位

AI 玩家需要模拟真人玩家的思维和行为，具备以下能力：
1. **逻辑推理** - 根据发言和局势分析
2. **语言表达** - 自然流畅的发言
3. **情绪模拟** - 适当的情绪反应
4. **策略选择** - 根据角色选择最优策略

## 各角色 AI 策略

### 预言家 AI

**核心目标**：让好人相信自己，找出狼人

**策略要点**：
1. **上警拿警徽** - 必须上警，争取警徽
2. **报查验** - 清晰报出昨晚查验结果
3. **留警徽流** - 明确接下来要验谁
4. **分析悍跳** - 指出对跳狼的漏洞
5. **请求站边** - 呼吁好人相信自己

**发言模板**：
```
我是预言家，昨晚验了{X}号是{金水/查杀}。
我的警徽流是：今晚验{Y}，如果Y是好人，明晚验{Z}。
验Y是因为...（给出理由）
对跳的{X}号是悍跳狼，因为...（分析漏洞）
好人请站边我，把悍跳狼投出去。
```

**应对悍跳**：
- 保持冷静，不要情绪化
- 指出对方发言的逻辑漏洞
- 强调自己的查验和警徽流
- 呼吁好人相信自己

### 狼人 AI

**核心目标**：隐藏身份，混淆视听，刀死好人

**策略选择**：

#### 悍跳狼
- 模仿预言家发言
- 给队友发金水，给好人发查杀
- 攻击真预言家
- 拉队友冲锋或倒钩

#### 倒钩狼
- 站边真预言家
- 攻击悍跳队友（适度）
- 获得信任后带节奏
- 关键时刻反水

#### 深水狼
- 发言像平民
- 不站边或模糊站边
- 关键时刻投票

**刀法策略**：
1. **首夜** - 刀预言家或外置位（不刀女巫）
2. **第二夜** - 刀明神职或站边明确的好人
3. **后期** - 刀关键神职或控场

### 女巫 AI

**核心目标**：用好解药和毒药，保护好人

**用药策略**：
- **首夜**：建议救人（除非有白狼王）
- **解药**：救预言家、救明好人
- **毒药**：毒明狼、毒狼王

**发言策略**：
- 可以暗示开药情况
- 警告狼人不要刀自己
- 分析死亡玩家和刀法

### 猎人 AI

**核心目标**：利用开枪能力威慑狼人

**策略要点**：
- 可以强势表水
- 不怕被投（有开枪能力）
- 威胁狼人不要惹自己
- 被刀后带走明狼

### 平民 AI

**核心目标**：认真听发言，找出狼人

**策略要点**：
1. **表水** - 清晰表达自己的逻辑
2. **站边** - 判断真假预言家
3. **找狼** - 分析谁的发言有问题
4. **挡刀** - 必要时假装神职

## AI 推理逻辑

### 信息收集
1. **查验信息** - 预言家的查验结果
2. **死亡信息** - 每晚死亡玩家
3. **发言信息** - 所有玩家的发言内容
4. **投票信息** - 投票行为和结果

### 逻辑推理
1. **身份推断** - 根据行为推断身份
2. **矛盾发现** - 找出发言矛盾
3. **狼坑计算** - 计算剩余狼人位置
4. **胜率评估** - 评估当前局势

### 决策制定
1. **技能使用** - 是否使用技能、对谁使用
2. **投票选择** - 投给谁
3. **发言内容** - 说什么、怎么说
4. **策略调整** - 根据局势调整策略

## AI 发言生成

### 发言结构
1. **开场** - 表明身份或立场
2. **分析** - 分析当前局势
3. **观点** - 表达自己的观点
4. **行动** - 呼吁或建议

### 语气模拟
- **自信** - 神职表水时
- **诚恳** - 请求站边时
- **愤怒** - 被踩或发现狼时
- **犹豫** - 不确定时
- **冷静** - 分析局势时

### 避免 AI 特征
- 不要发言过于完美
- 偶尔有小的逻辑漏洞
- 有情绪波动
- 不是每次都能准确判断

## RAG 知识库使用

### 检索时机
1. **角色技能** - 不确定技能效果时
2. **游戏规则** - 不确定规则时
3. **策略参考** - 需要策略建议时
4. **板子配置** - 不确定角色配置时

### 检索内容
- 当前板子的角色配置
- 自己角色的技能和策略
- 当前阶段的规则
- 常见套路和反套路

### 知识应用
1. **理解角色** - 明确自己的胜利条件和技能
2. **制定策略** - 根据角色选择策略
3. **生成发言** - 参考发言模板
4. **逻辑推理** - 利用规则进行推理

## 学习进化

### 对局记录
- 记录每局的关键决策
- 记录成功和失败的经验
- 分析对手的行为模式

### 策略优化
- 根据胜率调整策略
- 学习对手的反制手段
- 改进发言和推理能力

### 知识更新
- 学习新的板子和规则
- 了解流行的套路
- 更新策略库
