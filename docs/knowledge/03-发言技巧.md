# 狼人杀发言技巧

## 通用发言原则

### 1. 逻辑清晰
- 按时间线梳理事件
- 明确表达自己的观点和推理
- 避免前后矛盾

### 2. 态度诚恳
- 不要贴脸（情绪激动、场外威胁）
- 不要划水（发言无实质内容）
- 保持冷静分析

### 3. 有信息量
- 分享自己的视角和信息
- 分析其他玩家的发言和行为
- 提出有价值的质疑

## 各角色发言策略

### 预言家发言模板

**上警发言：**
```
我是预言家，昨晚验了X号，是金水/查杀。
我的警徽流是：今晚验Y，明晚验Z。
验Y是因为...，验Z是因为...
如果我对跳的是狼，请好人相信我。
```

**警下发言：**
```
我是真预言家，对跳的是悍跳狼。
我的查验是X金水/Y查杀。
警徽流是Y、Z。
请好人站边我，把对跳的狼投出去。
```

**要点：**
- 报查验要清晰
- 留警徽流（即使没警徽也要留）
- 分析对跳狼的漏洞
- 请求好人站边

### 狼人发言策略

**悍跳预言家：**
- 模仿真预言家的发言方式
- 给队友发金水，给好人发查杀
- 攻击真预言家的漏洞
- 拉队友冲锋或倒钩

**倒钩狼：**
- 站边真预言家
- 攻击悍跳队友（不要太狠）
- 获得好人信任后带节奏

**深水狼：**
- 发言像平民
- 不站边或模糊站边
- 关键时刻带节奏

**冲锋狼：**
- 强烈支持悍跳队友
- 攻击真预言家和站边好人
- 制造混乱

### 神职发言

**女巫：**
- 可以暗示自己开药情况
- 警告狼人不要刀自己
- 分析死亡玩家和刀法

**猎人：**
- 可以强势表水
- 不怕被投（有开枪能力）
- 威胁狼人不要惹自己

**守卫：**
- 暗示守护了谁
- 分析刀法和守人策略

### 平民发言

**表水（证明自己不是狼）：**
```
我是平民，没什么信息。
我觉得X号的发言有问题，因为...
我站边Y号预言家，因为...
```

**找狼：**
- 分析谁的发言像狼
- 找出逻辑矛盾
- 注意站边反复的人

## 高级技巧

### 1. 诈身份
- 假装有身份试探对方反应
- 平民可以诈女巫、诈预言家
- 观察对方是否慌张

### 2. 穿衣服
- 平民假装神职挡刀
- 神职假装平民躲刀
- 注意别穿崩了

### 3. 钓鱼执法
- 故意说错信息看谁会纠正
- 观察谁的信息量超出应有范围

### 4. 情绪控制
- 被踩不要激动
- 被保不要过于开心
- 保持平稳心态

## 常见错误

### 新手常犯的错误
1. **贴脸发言**："我要是狼我就..."、"我发誓..."
2. **场外信息**："他平时不是这样的"、"我看他表情..."
3. **划水**："我是好人，过"、"没什么可说的"
4. **自爆式发言**：暴露自己知道不该知道的信息

### 狼人常犯的错误
1. **信息过载**：知道太多（暴露队友）
2. **发言太满**：试图解释所有事情
3. **攻击队友**：倒钩太狠把队友卖了
4. **情绪失控**：被踩后反应过度

## 听发言技巧

### 找狼信号
- 发言前后矛盾
- 信息量异常（知道不该知道的）
- 过度解释自己的行为
- 攻击目标选择奇怪
- 站边反复无常

### 找好人信号
- 逻辑清晰自洽
- 视角干净（信息量正常）
- 敢于质疑和对抗
- 有明确的站边和理由

## 不同阶段发言重点

### 第一天白天
- 预言家对跳，判断真假
- 分析警上警下格局
- 找倒钩和冲锋

### 第二天白天
- 根据死亡信息推理
- 分析刀法和用药
- 缩小狼坑范围

### 后期残局
- 精确点狼坑
- 分析剩余角色
- 计算胜负条件
