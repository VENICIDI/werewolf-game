# 狼人杀游戏规则

## 游戏概述

狼人杀是一款多人参与的社交推理游戏，玩家分为狼人阵营和好人阵营，通过语言交流和逻辑推理找出敌对阵营玩家。

## 基本流程

### 1. 角色分配阶段
- 系统随机分配角色给每位玩家
- 玩家确认自己的身份（仅自己可见）
- 游戏开始，进入夜晚阶段

### 2. 夜晚阶段（闭眼阶段）
所有玩家闭眼，特定角色按顺序睁眼行动：

1. **狼人睁眼** - 确认队友，选择要击杀的目标
2. **预言家睁眼** - 选择一名玩家查验身份（好人/狼人）
3. **女巫睁眼** - 查看今晚死亡玩家，决定是否使用解药或毒药
4. **猎人睁眼** - 确认自己的技能状态
5. **其他角色** - 按规则执行相应行动

### 3. 白天阶段（睁眼阶段）
1. **公布死亡信息** - 宣布昨晚死亡的玩家（除非被女巫救活）
2. **遗言环节** - 死亡玩家发表遗言（首夜死亡有遗言）
3. **自由讨论** - 存活玩家轮流发言，分析推理
4. **投票环节** - 所有存活玩家投票选出最可疑的人
5. **处决公布** - 公布投票结果，得票最高者被处决
6. **遗言环节** - 被处决玩家发表遗言

### 4. 胜负判定
- **狼人胜利条件**：所有神职死亡 或 所有平民死亡
- **好人胜利条件**：所有狼人死亡

## 游戏配置

### 标准9人局
- 狼人：3人
- 预言家：1人
- 女巫：1人
- 猎人：1人
- 平民：3人

### 标准12人局
- 狼人：4人
- 预言家：1人
- 女巫：1人
- 猎人：1人
- 守卫：1人（可选）
- 平民：4人

## 重要规则

### 关于遗言
- 首夜死亡的玩家有遗言
- 白天被投票处决的玩家有遗言
- 被女巫毒死的玩家无遗言
- 猎人开枪带走的玩家无遗言

### 关于平票
- 如果投票出现平票，平票玩家进行PK发言
- PK发言后再次投票，如仍平票则无人被处决，进入下一夜

### 关于自爆
- 狼人可以在白天任何阶段自爆
- 自爆后立即进入夜晚，自爆狼人无遗言
- 自爆可以打断当前发言或投票

### 关于连续两夜
- 同一玩家不能连续两晚被狼人击杀（守卫守护除外）
- 女巫不能连续两晚使用解药

## 术语解释

| 术语 | 含义 |
|------|------|
| 上警 | 竞选警长 |
| 警徽流 | 预言家计划查验的玩家顺序 |
| 金水 | 预言家查验的好人 |
| 查杀 | 预言家查验的狼人 |
| 悍跳 | 狼人假扮预言家 |
| 倒钩 | 狼人假装站边真预言家 |
| 冲锋 | 狼人支持悍跳狼队友 |
| 划水 | 发言没有实质内容 |
| 贴脸 | 用情绪或场外信息威胁 |
| 场外 | 利用游戏外信息推理 |
