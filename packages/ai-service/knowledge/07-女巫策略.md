# 女巫策略

## 解药使用策略

### 第一晚是否救人

#### 救的理由
- 被刀的可能是预言家等核心神职
- 救人可以保持好人数量优势
- 第一晚信息少，被刀的大概率是好人

#### 不救的理由
- 不确定被刀的人是否是核心角色
- 保留解药等待更关键的时刻
- 如果被刀的是村民，解药价值较低

### 解药使用决策树

```
被刀的人是谁？
├─ 确定是预言家 → 必须救
├─ 确定是重要神职 → 大概率救
├─ 不确定身份
│  ├─ 第一晚 → 倾向于救（概率上值得）
│  └─ 后续回合
│     ├─ 场上好人数量紧张 → 救
│     └─ 场上好人数量充裕 → 可以不救
└─ 确定是普通村民 → 看局势决定
```

### 核心原则
- 救神职的优先级远高于救村民
- 如果预言家已跳身份且被刀，必须救
- 后期（第3天以后）解药的价值更高，因为每个人头都关键

## 毒药使用策略

### 毒药使用时机

#### 高确定性使用
- 预言家查杀了某人且可信度高 → 直接毒
- 有充分证据确认某人是狼人 → 毒
- 场上已经锁定狼人但白天投票投不出去 → 夜晚毒

#### 需要谨慎的情况
- 仅凭一个人的指认 → 不要急着毒
- 第一晚盲毒 → 非常不建议，风险太大
- 场上信息混乱时 → 保留毒药等待更多信息

### 毒药使用决策树

```
是否要使用毒药？
├─ 有确凿证据（查杀/多人指认）→ 毒
├─ 只有怀疑 → 不毒，等更多信息
├─ 第一晚 → 极不建议盲毒
└─ 最后关头（输赢一线）→ 根据概率判断毒
```

### 毒药的战略价值
- 毒药相当于一次额外的"投票出局"
- 可以在夜晚绕过狼人的投票优势
- 在好人投票困难时是关键手段

## 女巫的信息优势

### 刀口信息
女巫每晚都知道谁被狼人选择击杀，这是重要信息：
- 如果某人被刀说明狼人认为他有威胁
- 连续被守卫守住的位置可能暴露守卫方向
- 女巫可以根据刀口判断狼人的意图

### 信息利用
- 可以在发言时暗示刀口信息（但不要直接说自己是女巫）
- 通过刀口信息推测哪些位置可能是狼人
- 结合查验信息和刀口信息交叉分析

## 女巫跳身份时机

### 什么时候跳女巫
- 被怀疑即将被投票出局时
- 需要公布关键信息时
- 预言家已死，需要另一个可信信息源时
- 游戏后期需要用毒药信息证明自己

### 跳身份后的策略
- 公布用药记录（救了谁、有没有毒人）
- 公布每晚的刀口信息
- 用信息帮助好人做判断
- 注意跳身份后成为狼人重点目标

## 同守冲突的注意事项

如果守卫和女巫在同一晚保护了同一个人，该玩家仍然会死亡。女巫在决定救人时应注意：
- 如果预言家已跳身份，守卫可能在守预言家
- 救被刀的跳了身份的预言家有同守冲突风险
- 需要权衡同守风险和不救的风险
